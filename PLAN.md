# github-ripple

A GitHub Action that turns your repo's contributors into pixel-art characters drifting on tubes across a wavy ocean, rendered as an animated SVG in your README.

## Concept

- Horizontal SVG banner (680×290 viewBox)
- Sky (~60%) + ocean (~40%), with sun and clouds for decoration
- Three wave layers (back / mid / front), each scrolling horizontally at a different speed
- Each contributor gets a group of: tube + 16×16 pixel avatar + ID label, drifting left → right
- Each group bobs up and down slightly
- No hover/click interactions (GitHub renders READMEs' SVGs via `<img>`, which kills interactivity). All info is always visible.

## Cost

Completely free.
- Publishing to the GitHub Actions Marketplace: free, no review
- Running Actions on public repos: free
- API calls authenticated with `GITHUB_TOKEN` get 1000 req/hour — plenty for this use case

## Tech stack

- Node.js 20 + TypeScript
- `@octokit/rest` — GitHub API
- `sharp` — avatar downsampling to 16×16
- `tsx` — run TS directly
- pnpm recommended (npm/yarn also fine)

### 1-2. `scripts/fetch-contributors.ts`

```typescript
import { Octokit } from '@octokit/rest';

export interface Contributor {
  login: string;
  avatarUrl: string;
  contributions: number;
}

export async function fetchContributors(opts: {
  owner: string;
  repo: string;
  token?: string;
  max: number;
  excludeBots: boolean;
}): Promise<Contributor[]> {
  const octokit = new Octokit({ auth: opts.token });
  const res = await octokit.repos.listContributors({
    owner: opts.owner,
    repo: opts.repo,
    per_page: 100,
  });
  let list = res.data
    .filter(c => c.login && c.avatar_url)
    .map(c => ({
      login: c.login!,
      avatarUrl: c.avatar_url!,
      contributions: c.contributions ?? 0,
    }));
  if (opts.excludeBots) {
    list = list.filter(c => !c.login.endsWith('[bot]'));
  }
  list.sort((a, b) => b.contributions - a.contributions);
  return list.slice(0, opts.max);
}
```

### 1-3. `scripts/fetch-avatars.ts`

```typescript
import sharp from 'sharp';

export async function fetchAvatarBase64(url: string): Promise<string> {
  const res = await fetch(`${url}&s=64`); // GitHub avatar URL params
  const buf = Buffer.from(await res.arrayBuffer());
  const resized = await sharp(buf)
    .resize(16, 16, { kernel: 'nearest' })
    .png()
    .toBuffer();
  return `data:image/png;base64,${resized.toString('base64')}`;
}
```

> **Note**: use `kernel: 'nearest'` for the downsample to preserve the chunky pixel look. Inside the SVG, upscale 16×16 to 32×32 with `image-rendering="pixelated"` so the dots stay crisp.

### 1-4. `scripts/hash.ts` — deterministic distribution

So the same person always appears with the same look / speed.

```typescript
function hashStr(s: string): number {
  let h = 2166136261;
  for (let i = 0; i < s.length; i++) {
    h ^= s.charCodeAt(i);
    h = Math.imul(h, 16777619);
  }
  return h >>> 0;
}

export interface CharParams {
  tubeColor: string;
  tubeHighlight: string;
  yPos: number;          // 195~220
  duration: number;      // 18~28s
  beginOffset: number;   // -dur~0
  bobDuration: number;   // 2.2~3.0s
  bobPhase: 'up' | 'down';
}

const TUBE_PALETTE = [
  { main: '#f472b6', highlight: '#fbcfe8' }, // pink
  { main: '#facc15', highlight: '#fef08a' }, // yellow
  { main: '#84cc16', highlight: '#bef264' }, // lime
  { main: '#fb923c', highlight: '#fed7aa' }, // orange
  { main: '#60a5fa', highlight: '#bfdbfe' }, // blue
  { main: '#c084fc', highlight: '#e9d5ff' }, // purple
];

export function paramsFor(login: string, index: number, total: number): CharParams {
  const h = hashStr(login);
  const palette = TUBE_PALETTE[h % TUBE_PALETTE.length];
  const yPos = 195 + (h >> 4) % 26;                  // 195~220
  const duration = 18 + ((h >> 8) % 11);              // 18~28s
  const bobDuration = 2.2 + (((h >> 12) % 9) / 10);   // 2.2~3.0
  // Evenly distribute begin offsets so characters don't pile up
  const beginOffset = -(duration * index / total);
  const bobPhase = ((h >> 16) % 2) === 0 ? 'up' : 'down';
  return {
    tubeColor: palette.main,
    tubeHighlight: palette.highlight,
    yPos,
    duration,
    beginOffset,
    bobDuration,
    bobPhase,
  };
}
```

### 1-5. `scripts/build-svg.ts`

Use the **Reference SVG** below as a template, then dynamically generate one character `<g>` per contributor.

Core structure:

```typescript
import type { Contributor } from './fetch-contributors';
import { paramsFor } from './hash';

interface ContributorWithAvatar extends Contributor {
  avatarDataUri: string;
}

export function buildSvg(contributors: ContributorWithAvatar[]): string {
  const characters = contributors
    .map((c, i) => buildCharacterGroup(c, i, contributors.length))
    .join('\n');

  return `<svg width="100%" viewBox="0 0 680 290" xmlns="http://www.w3.org/2000/svg" role="img">
<title>Contributors</title>
<desc>Floating pixel contributors on waves</desc>
${BACKGROUND_LAYERS}
${BACK_WAVE}
${MID_WAVE}
${characters}
${FRONT_WAVE}
</svg>`;
}

function buildCharacterGroup(c: ContributorWithAvatar, i: number, total: number): string {
  const p = paramsFor(c.login, i, total);
  const bobValues = p.bobPhase === 'up'
    ? '0,-3;0,3;0,-3'
    : '0,3;0,-3;0,3';

  return `<g>
  <animateTransform attributeName="transform" type="translate"
    from="-60,${p.yPos}" to="740,${p.yPos}"
    dur="${p.duration}s" begin="${p.beginOffset}s" repeatCount="indefinite"/>
  <g>
    <animateTransform attributeName="transform" type="translate"
      values="${bobValues}" dur="${p.bobDuration}s" repeatCount="indefinite"/>
    <ellipse cx="0" cy="14" rx="24" ry="3" fill="#0c4a6e" opacity="0.3"/>
    <ellipse cx="0" cy="2" rx="24" ry="8" fill="${p.tubeColor}"/>
    <rect x="-3" y="-5" width="6" height="3" fill="${p.tubeHighlight}"/>
    <rect x="-20" y="-1" width="3" height="4" fill="${p.tubeHighlight}"/>
    <ellipse cx="0" cy="2" rx="12" ry="4" fill="#38bdf8"/>
    <image href="${c.avatarDataUri}" x="-16" y="-30" width="32" height="32"
      image-rendering="pixelated" style="image-rendering: pixelated;"/>
    <text y="22" font-family="monospace" font-size="11" font-weight="bold"
      fill="#ffffff" text-anchor="middle"
      stroke="#0c4a6e" stroke-width="3" paint-order="stroke">@${c.login}</text>
  </g>
</g>`;
}
```

> **Important**: by embedding the pixelated PNG avatar directly via SVG `<image>`, we skip the hand-drawn pixel face from the demo. A 16×16 PNG rendered into a 32×32 area with `image-rendering="pixelated"` gives the dot-graphic look automatically.

### 1-6. `scripts/generate.ts` — entry point

```typescript
import { Command } from 'commander';
import { fetchContributors } from './fetch-contributors';
import { fetchAvatarBase64 } from './fetch-avatars';
import { buildSvg } from './build-svg';
import { writeFileSync } from 'fs';

const program = new Command();
program
  .requiredOption('--owner <owner>')
  .requiredOption('--repo <repo>')
  .option('--output <path>', 'output path', 'ripple.svg')
  .option('--token <token>', 'GitHub token (env: GITHUB_TOKEN)')
  .option('--max <n>', 'max contributors', '20')
  .option('--exclude-bots', 'exclude [bot] accounts', true);
program.parse();
const opts = program.opts();

const token = opts.token ?? process.env.GITHUB_TOKEN ?? process.env.TOKEN;

const contributors = await fetchContributors({
  owner: opts.owner,
  repo: opts.repo,
  token,
  max: parseInt(opts.max, 10),
  excludeBots: opts.excludeBots,
});

const withAvatars = await Promise.all(
  contributors.map(async c => ({
    ...c,
    avatarDataUri: await fetchAvatarBase64(c.avatarUrl),
  }))
);

const svg = buildSvg(withAvatars);
writeFileSync(opts.output, svg);
console.log(`✅ ${withAvatars.length} contributors → ${opts.output}`);
```

## Phase 2 — Wrap it as a GitHub Action

### 2-1. `action.yml` (repo root)

```yaml
name: 'GitHub Ripple'
description: 'Floating pixel contributors on waves for your README'
author: 'your-github-id'
branding:
  icon: 'droplet'
  color: 'blue'
inputs:
  output-path:
    description: 'Where to write the SVG'
    default: 'assets/ripple.svg'
  max-contributors:
    description: 'Max contributors shown'
    default: '20'
  exclude-bots:
    description: 'Exclude [bot] accounts'
    default: 'true'
  token:
    description: 'GitHub token (defaults to github.token)'
    default: ${{ github.token }}
runs:
  using: 'composite'
  steps:
    - uses: actions/setup-node@v4
      with:
        node-version: '20'
    - name: Install deps
      run: pnpm install --frozen-lockfile
      working-directory: ${{ github.action_path }}
      shell: bash
    - name: Generate SVG
      run: pnpm tsx scripts/generate.ts --owner="$OWNER" --repo="$REPO" --output="$OUTPUT" --max="$MAX" ${EXCLUDE_BOTS:+--exclude-bots}
      working-directory: ${{ github.action_path }}
      shell: bash
      env:
        OWNER: ${{ github.repository_owner }}
        REPO: ${{ github.event.repository.name }}
        OUTPUT: ${{ github.workspace }}/${{ inputs.output-path }}
        MAX: ${{ inputs.max-contributors }}
        EXCLUDE_BOTS: ${{ inputs.exclude-bots == 'true' && '1' || '' }}
        GITHUB_TOKEN: ${{ inputs.token }}
```

> `working-directory: ${{ github.action_path }}`: installs deps and runs from where the action code lives. `${{ github.workspace }}`: the user's checked-out repo. Output must be written to the user's repo, not the action's directory.

### 2-2. `.github/workflows/ripple.yml` (self-dogfood)

```yaml
name: Ripple
on:
  schedule:
    - cron: '0 0 * * *'
  workflow_dispatch:
  push:
    branches: [main]

permissions:
  contents: write

jobs:
  splash:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: ./    # use the action.yml at the root of this repo
        with:
          output-path: assets/ripple.svg
      - uses: stefanzweifel/git-auto-commit-action@v5
        with:
          commit_message: '🌊 ripple update'
          file_pattern: 'assets/ripple.svg'
```

### 2-3. Repo Settings

- Settings → Actions → General → **Workflow permissions**
- Select **"Read and write permissions"** and save
- Without this, the commit step will fail with a permission error

### 2-4. Embed in README

```markdown
## Contributors

![ripple](assets/ripple.svg)
```

After pushing, the action runs and the SVG shows up in the README shortly after.

## Design parameters (reference)

### Canvas
- viewBox: `0 0 680 290`
- Sky: y 0~180, water: y 180~290
- Sun: cx=600 cy=55 r=22 (#fde68a)

### Character region
- Outer group y range: 195~220
- Tube ellipse: rx=24, ry=8, cy=2 (group-local)
- Avatar: positioned at -16,-30 with size 32×32 (pixelated upscale from 16×16)
- ID label: y=22, white fill with 3px dark-navy stroke

### Animation
- Horizontal traverse: dur 18~28s, `from="-60,Y" to="740,Y"`
- Begin offset: `-dur * index / total` to evenly distribute
- Bob: 2.2~3.0s, ±3px, randomized phase
- Wave back: 18s period, -340 translate
- Wave mid: 11s period, -272 translate
- Wave front: 7s period, -204 translate (drawn in front of characters)

## Edge cases

- **0 contributors**: fall back to an empty ocean, maybe a lone seagull. Or just the empty ocean.
- **Too many (50+)**: cap with the `max` option. Sort by contributions descending.
- **Skip commit if unchanged**: hash the new SVG against the existing one; if equal, don't write the file → `git-auto-commit-action` will report "nothing to commit".
- **Non-ASCII logins**: GitHub logins are ASCII-only, so no concern. Display names aren't fetched.
- **Private repos**: works as long as `GITHUB_TOKEN` has read access. The workflow's `permissions: contents: write` plus the automatic token is enough.
- **Rate limit**: `GITHUB_TOKEN` allows 1000 req/hour. Each run uses 1 contributors-list call + N avatar fetches, so well under the limit.
